### Step 1: Generate and Copy Your Robylon Chatbot Embed Code.

1. Log in to your Robylon account and open the dashboard.
2. In the left panel, click on the settings button to navigate to the settings page.

   <Frame>
     ![Robylon dashboard with the left sidebar open and Settings selected to configure your chatbot](/Robylon1.png)
   </Frame>
3. Within the settings tab, select [<u>Channels</u>](https://app.robylon.ai/settings/channels).

   <Frame>
     ![Settings → Channels screen in the Robylon dashboard for bot integrations](/Robylon2.png)
   </Frame>
4. Click on the [<u>Chatbot</u>](https://app.robylon.ai/settings/channels/chatbot/interface) widget to access the chatbot details.

   <Frame>
     ![Channels page with the Chatbot widget selected to access bot details](/Robylon3.png)
   </Frame>
5. Navigate to the [<u>Install</u>](https://app.robylon.ai/settings/channels/chatbot/install) tab within the chatbot details page.

   <Frame>
     ![Chatbot details showing the Install tab for adding the widget to Bubble](/Robylon4.png)
   </Frame>
6. Select JavaScript to embed code in Bubble.

   <Frame>
     ![Install tab with the JavaScript embed option chosen for Bubble apps](/Robylon5JS.png)
   </Frame>
7. Copy the provided chatbot embed code.

   <Frame>
     ![Robylon chatbot Bubble integration embed code snippet in the dashboard](/Robylon6JS.png)
   </Frame>

### **Step 2**: Embed Robylon Chatbot on Your Bubble App

1. Once you’ve copied your Robylon embed code, sign in to your Bubble account and head to your account dashboard.
2. On your dashboard, pick the Bubble app or website you wish to embed the chatbot on.

   <Frame>
     ![Bubble dashboard to pick the app or page where the Robylon chatbot will be embedded](/images/Bubble1.png)
   </Frame>
3. Scroll down to the section of the page you want to add the embed code.
4. On the left sidebar of the editor, locate the HTML component and drag it to any section of the page to add a chatbot.

   <Frame>
     ![Bubble editor: drag the HTML element from the left sidebar onto the page for Robylon chatbot integration](/images/Bubble2.png)
   </Frame>
5. Double-click on the HTML component to reveal the code editor.

   <Frame>
     ![Double-click the HTML element in Bubble to open the code editor](/images/Bubble3.png)
   </Frame>
6. Paste the Robylon Embed code copied earlier into the editor.

   <Frame>
     ![Paste the Robylon embed code into the Bubble HTML editor](/images/Bubble4.png)
   </Frame>
7. You can now preview your Bubble app to test your chatbot.

   <Frame>
     ![Preview the Bubble app to test the Robylon chatbot integration](/images/Bubble5.png)
   </Frame>
   <Frame>
     ![Page preview showing the Robylon chatbot launcher visible on the site](/images/Bubble6.png)
   </Frame>
   <Frame>
     ![Chat window open, confirming the Robylon chatbot works inside the Bubble app](/images/Bubble7.png)
   </Frame>
