### **Step 1: Generate and Copy Your Robylon Chatbot Embed Code.**

1. Log in to your Robylon account and open the dashboard.
2. In the left panel, click on the settings button to navigate to the settings page.

   <Frame>
     ![Robylon dashboard showing the Settings menu to start Webflow chat widget setup](/Robylon1.png)
   </Frame>
3. Within the settings tab, select [<u>Channels</u>](https://app.robylon.ai/settings/channels).

   <Frame>
     ![Robylon Settings → Channels screen highlighting Chatbot channel selection](/Robylon2.png)
   </Frame>
4. Click on the [<u>Chatbot</u>](https://app.robylon.ai/settings/channels/chatbot/interface) widget to access the chatbot details.

   <Frame>
     ![Robylon Chatbot widget page where the Install tab is accessed](/Robylon3.png)
   </Frame>
5. Navigate to the [<u>Install</u>](https://app.robylon.ai/settings/channels/chatbot/install) tab within the chatbot details page.

   <Frame>
     ![Robylon Install tab set to JavaScript embed for Webflow integration](/Robylon4.png)
   </Frame>
6. Select JavaScript to embed code in Webflow.

   <Frame>
     ![Robylon5js PnJavaScript embed code option selected in Robylon for Webflow embed](/Robylon5JS.png)
   </Frame>
7. Copy the provided chatbot embed code.

   <Frame>
     ![Copy the embed code snippet for Robylon chatbot to use in Webflow pages](/Robylon6JS.png)
   </Frame>

### **Step 2**: Embed the code in Webflow to Display Your Chatbot Widget 

1. To embed the code in Webflow, log in to your Webflow account and go to your dashboard.
2. Hover over the website you want to add the chatbot to and click on “Open in Webflow”.

   <Frame>
     ![On the Webflow dashboard listing’s workspace, select which site to embed the Robylon chatbot](/images/Webflow1.png)
   </Frame>
3. On the designer page, click on the file icon (Pages) in the left navbar of the Webflow site designer.

   <Frame>
     ![Webflow page settings icon, opening the custom code area for chatbot embed](/images/Webflow2.png)
   </Frame>
4. Hover over the page you want to embed the chatbot on and click on the settings icon of that page.

   <Frame>
     ![In the pages panel, select the Edit Page Settings gear icon to configure the Home page before adding Robylon chatbot script](/images/Webflow3.png)
   </Frame>
5. Scroll down in the settings panel of that page till you reach the Custom code section. Paste the Robylon chatbot copied code in the custom code section inside the head tag. Then save the changes.

   <Frame>
     ![Webflow page’s Custom Code section with "Paste embed code in head tag" instruction](/images/Webflow4.png)
   </Frame>
6. Publish your website for staging to see the chat icon on that page.

   <Frame>
     ![Webflow publish settings screen showing staging and production domains for deploying Robylon chatbot integration](/images/Webflow5.png)
   </Frame>
7. Test the chatbot to see if it works fine, then you can publish it for production.

   <Frame>
     ![Webflow site with Robylon chatbot launcher icon visible in the bottom-right corner after integration](/images/Webflow6.png)
   </Frame>
   <Frame>
     ![Webflow post-publish preview showing Robylon chatbot launcher on the site](/images/Webflow7.png)
   </Frame>
